# Pitch deck

`MarginGraph_pitch_deck.pptx` (14 slides, 16:9) is generated by `build.js` (pptxgenjs). Charts are native PowerPoint charts, every slide has speaker notes.

Numbers come from `docs/RESULTS.md` (UCI), `docs/RESULTS_PUBLIC.md` (five datasets, PR #17) and `results/retail_sim/` (store simulation, PR #18), the same sources as `paper/main.tex`.

```bash
npm install pptxgenjs react react-dom react-icons sharp
NODE_PATH=./node_modules SKILL=<pptx skill dir> node docs/deck/build.js MarginGraph_pitch_deck.pptx
```

`build.js` needs `apply_theme.js` from the pptx skill (path via `SKILL`) to write the theme colors.
