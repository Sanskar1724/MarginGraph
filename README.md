> This branch holds only the **Project report & roadmap** module of [MarginGraph](https://github.com/Sanskar1724/MarginGraph), a margin-aware e-commerce recommender (LightGBM ranker + MILP optimizer). The integrated, runnable project lives on `main`.

## What this module does

Written for readers who want the story without the code: why recommenders should care about margin, how MarginGraph works, what the experiments showed (and what failed, like the zero-shot LLM), and the plan for a pilot store and A/B test on free tools.
