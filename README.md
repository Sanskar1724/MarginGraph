> This branch holds only the **Launch kit** module of [MarginGraph](https://github.com/Sanskar1724/MarginGraph), a margin-aware e-commerce recommender (LightGBM ranker + MILP optimizer). The integrated, runnable project lives on `main`.

## What this module does

Everything needed to approach a pilot store and announce the project. The landing page deploys to GitHub Pages from `docs/launch/site/`.

## What's in this branch

| Path | What it is |
| --- | --- |
| `docs/launch/` | All launch documents |
| `docs/launch/site/index.html` | Landing page |
| `.github/workflows/pages.yml` | Pages deploy workflow |
| `docs/worklog/launch.md` | Work log |

## Run it

Open [`docs/launch/README.md`](docs/launch/README.md). The site deploys from `main` once Pages is enabled.
